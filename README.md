# FinanceAnalysisSystem

Система анализа финансовых результатов малого предприятия на WPF (.NET Framework)

## 📋 Описание

Приложение для управления финансами малого предприятия с функциями:
- ✅ Добавление доходов и расходов
- ✅ Категоризация операций
- ✅ Расчет ключевых финансовых показателей (прибыль, рентабельность)
- ✅ Генерация финансовых отчетов
- ✅ Сохранение данных в JSON
- ✅ Удобный интерфейс WPF

## 🏗️ Архитектура

```
FinanceAnalysisSystem/
├── Models/              # Модели данных
├── Services/            # Бизнес-логика
├── ViewModels/          # MVVM ViewModels
├── Views/               # WPF XAML и CodeBehind
├── Utils/               # Утилиты
└── App.xaml             # Конфигурация приложения
```

## 🚀 Запуск

1. Откройте проект в Visual Studio
2. Нажмите F5 или запустите проект
3. Используйте интерфейс для добавления финансовых операций

## 💾 Сохранение данных

Данные автоматически сохраняются в `C:\Users\[YourUsername]\Documents\FinanceAnalysisSystem\transactions.json`

## 📊 Функции

- **Добавить операцию** - добавление новой операции с типом (доход/расход), категорией и суммой
- **Просмотреть отчет** - получение детального финансового отчета
- **Удалить операцию** - удаление операции из списка
- **Автосохранение** - данные сохраняются при каждом изменении

## 📈 Показатели в отчете

- Общий доход
- Общие расходы  
- Чистая прибыль
- Маржа прибыли (%)
- Рентабельность по доходам (%)
- Распределение по категориям
